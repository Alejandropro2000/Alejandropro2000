# InfoConfidencial PY (Aplicación de Escritorio)

Aplicación de escritorio para notebook/PC que permite realizar consultas de identidad por **Cédula Paraguaya** y visualizar módulos de:

- Ubicabilidad para cobranzas
- Disminución de riesgos en otorgamiento de crédito
- Historial de antecedentes para RRHH
- Datos referenciales disponibles en la plataforma

## Requisitos

- Windows 10/11 (recomendado)
- Python 3.10 o superior

## Ejecutar en modo desarrollo

1. Abrir terminal en esta carpeta.
2. Ejecutar:
   ```bash
   python app.py
   ```

## Crear ejecutable instalable (Windows)

1. Doble clic en `build_windows.bat`.
2. Esperar a que finalice la compilación.
3. Abrir `dist\InfoConfidencialPY.exe`.

## Nota

Los datos cargados en esta demo se encuentran en `data/sample_records.json` y son de ejemplo.
